subtitle: Signed TypeScript client for the Enterprise API

<Warning>
Server-side use only. `SafeRxClient` signs every request with your Enterprise
API key as the HMAC secret. Never import this package, bundle it, or embed
your API key in code that runs in a browser, mobile WebView, or any other
client-controlled environment — doing so exposes the signing secret to
whoever can open dev tools. Call the Enterprise API from your backend, then
serve only the results to the browser.
</Warning>

```bash
npm install saferx-pharma-sdk
```

```typescript
import { SafeRxClient } from "saferx-pharma-sdk";

const client = new SafeRxClient(
  "https://saferx.online/api/enterprise/v1",
  process.env.SAFERX_API_KEY!,
);

const result = await client.request("enterprise_safety_check", {
  body: {
    locale: "en",
    medications: [{ input_text: "Augmentin 1g" }],
    requested_domains: ["ddi"],
  },
  idempotencyKey: "safety-check-001",
});
```

The client signs the exact method, path, query, body digest, timestamp, and nonce before sending.
