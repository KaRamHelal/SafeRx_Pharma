---
title: MCP adapter
subtitle: Bounded tool access for AI hosts
---

The MCP adapter exposes only the approved Enterprise tool projection. It forwards calls to Enterprise routes, preserves typed problem outcomes, and must not invent safety conclusions from missing or unavailable domains.

```bash
SAFERX_API_KEY=YOUR_ENTERPRISE_KEY npx @saferx_pharma/mcp-server
```

The adapter signs the Enterprise request. Keep the key in the host environment, not in the MCP configuration committed to a repository. Tool names and input shapes are bound to the checked-in contract.
