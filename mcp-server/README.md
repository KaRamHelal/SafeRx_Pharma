# SafeRx Enterprise MCP integration

This directory contains a separately controlled MCP integration. It is not a
public API surface, public package-availability claim, or substitute for the
published authenticated Enterprise REST contract.

Internal release consumers receive deployment and configuration instructions
through the appropriate controlled channel. Internal tool names, routes,
schemas, credentials, and artifact locations are intentionally not documented
in this public repository.

## Build

```bash
npm ci
npm run build
```
