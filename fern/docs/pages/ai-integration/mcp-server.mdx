## Overview

The SafeRx MCP Server wraps the Drug Safety API as a Model Context Protocol server, enabling direct integration with AI tools that support MCP.

## Tools

| Tool | Description |
|------|-------------|
| `check_drug_safety` | Screen drugs across all seven safety domains, including clinical dose context and allergy matching |
| `get_drug_metadata` | Get available populations, conditions, database versions, domain codes, and current tier limits |

## Installation

```bash
SAFERX_API_KEY=sfx_free_... npx @saferx_pharma/mcp-server
```

An API key is required. [Get a free key](/api-reference/authentication/api-keys) to get started.

## Configuration

Add to your Claude Desktop config (`claude_desktop_config.json`):

```json
{
  "mcpServers": {
    "saferx": {
      "command": "npx",
      "args": ["-y", "@saferx_pharma/mcp-server"],
      "env": {
        "SAFERX_API_KEY": "sfx_free_..."
      }
    }
  }
}
```

## Patient Context

Pass `patient_profile` when you need clinically useful output for medical, pharmacy, clinic management, or ERP workflows:

```json
{
  "drugs": ["Augmentin 1g", "Marivan"],
  "patient_profile": {
    "age": 72,
    "crcl": 25,
    "conditions": ["hypertension"],
    "allergies": ["penicillin"]
  },
  "include": ["clinical", "dose", "allergy"]
}
```

Useful response paths:

| Need | Response path |
|------|---------------|
| Resolved product identity | `drugs[].sfrx_id`, `drugs[].display_name`, `drugs[].route` |
| Renal/hepatic/pediatric context applied | `safety.clinical.context_applied` |
| Matched dose recommendations | `safety.clinical.population_alerts[].dose_recommendation` |
| Monitoring instructions | `safety.clinical.population_alerts[].monitoring_display` |
| Dose limits and standard-dose summaries | `safety.dosing[<sfrx_id>]` |
| Allergy family and cross-reactivity reference | `safety.allergy.product_families` |
| Patient allergy warnings | `safety.allergy.alerts` |

## Architecture

The MCP server is a thin HTTP wrapper:

```
AI Client (Claude/Cursor) → MCP Protocol → SafeRx MCP Server → HTTPS → SafeRx API
```

All authentication, rate limiting, and security is handled by the API layer. The MCP server simply translates MCP tool calls into HTTP requests.
