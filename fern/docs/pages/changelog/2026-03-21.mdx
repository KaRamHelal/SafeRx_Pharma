# March 21, 2026

## V102 Main Registry — Database Expansion

**Product coverage expanded from 28,557 to 66,704 products.**

The SafeRx drug registry has been upgraded to V102, more than doubling the product database with a unified three-tier classification:

| Tier | Count | Description |
|------|-------|-------------|
| Pharmaceutical | 22,062 | Prescription and OTC medications |
| Semi-pharmaceutical | 11,556 | Medical devices, supplements with therapeutic claims |
| Non-pharmaceutical | 33,086 | Health products, cosmetics, wellness items |

### What's New

- **Product tiers** — all products now classified as pharmaceutical, semi-pharmaceutical, or non-pharmaceutical
- **Product families** — related products (different strengths, forms) linked via parent hierarchy
- **Expanded metadata** — clinical uses, indications, dosing information, mechanism of action, and warnings now available for most products
- **Arabic enrichment** — bilingual name, description, and ingredient data across all tiers
- **Stock availability** — real-time stock status indicator

### API Impact

The drug resolution engine now matches against the expanded 66,704-product database. Several response field names were updated as part of the V102 migration — see the [March 25 changelog](/guides/changelog/2026-03-25) for the complete field mapping and SDK update instructions.
