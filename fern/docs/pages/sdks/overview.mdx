title: SDKs
subtitle: Signing-aware Enterprise client sources
---

The repository clients are generated from `openapi/enterprise-v1.yaml` and use the same operation IDs and HMAC request contract as the REST surface.

| Language | Source | Release state |
|---|---|---|
| Python | `sdks/python` | Internal release source |
| TypeScript | `sdks/typescript` | Internal release source |
| C# | `sdks/csharp` | Internal release source |

These checked-in sources are generated integration artifacts. They are not
published package availability claims; use the raw signed REST contract unless
your organization has received an SDK release through the MIS release process.
