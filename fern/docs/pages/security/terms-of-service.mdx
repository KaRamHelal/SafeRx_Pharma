subtitle: SafeRx Enterprise API terms
---

The Enterprise API is available under an issued API key — self-service for
the existing `enterprise_free` plan (see [Developer access](/authentication/developer-portal)),
admin-assigned for larger plans. It does not grant dispensing authority or
replace professional review. Use requires compliance with the published
terms at [saferx.online/terms](https://saferx.online/terms).
