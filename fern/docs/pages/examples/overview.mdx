## 1. Authentication Setup

All examples use API key authentication via the `X-SafeRx-API-Key` header. Get a free key via email verification:

```bash
# Step 1: Request verification code
curl -X POST https://saferx.online/api/developers/keys/free \
  -H "Content-Type: application/json" \
  -d '{"email":"you@example.com"}'
# Check your email for 6-digit code

# Step 2: Verify and receive key
curl -X POST https://saferx.online/api/developers/keys/free/verify \
  -H "Content-Type: application/json" \
  -d '{"email":"you@example.com","code":"123456"}'
```

## 2. Basic Safety Check

```python
resp = httpx.post(
    "https://saferx.online/api/drug_safety/check",
    headers=HEADERS,
    json={"drugs": ["Augmentin 1g", "Glucophage 500mg", "Marivan"]},
)
result = resp.json()
print(f"Resolved: {result['meta']['resolved_count']}/{result['meta']['drug_count']}")
```

## 3. Patient Profile with Populations and Conditions

Pass `patient_profile` to get population- and condition-specific safety alerts.

**Populations** (5): `pediatric`, `geriatric`, `cardiac`, `hepatic`, `renal`

**Conditions** (14): `arrhythmia`, `asthma`, `bph`, `coronary`, `depression`, `diabetes`, `epilepsy`, `gi_bleeding`, `glaucoma`, `heart_failure`, `hypertension`, `hyperthyroidism`, `hypothyroidism`, `parkinsons`

```python
resp = httpx.post(
    "https://saferx.online/api/drug_safety/check",
    headers=HEADERS,
    json={
        "drugs": ["Augmentin 1g", "Glucophage 500mg"],
        "patient_profile": {
            "populations": ["geriatric", "renal"],
            "conditions": ["diabetes", "hypertension"],
        },
    },
)
```

## 4. Selective Domain Inclusion

Use `include` to request only the safety domains you need. This reduces response size and latency.

| Code | Domain | What it returns |
|------|--------|-----------------|
| `ae` | Adverse Effects | Black Box Warnings, side effects, monitoring, dose classification |
| `ddi` | Drug Interactions | Severity-rated interactions with management advice (needs 2+ drugs) |
| `pllr` | Reproductive Safety | Pregnancy & lactation risk per trimester |
| `food` | Food Interactions | Meal timing, specific food conflicts |
| `clinical` | Clinical | Population & condition alerts (enhanced with `patient_profile`) |
| `dose` | Dosing | Max daily dose with WHO DDD + OpenFDA MDD dual-source data |

Omit `include` to run all six domains.

```python
# DDI-only check (fastest, smallest response)
resp = httpx.post(
    "https://saferx.online/api/drug_safety/check",
    headers=HEADERS,
    json={
        "drugs": ["Augmentin 1g", "Marivan"],
        "include": ["ddi"],
    },
)
```

## 5. Error Handling with Retry

```python
import random
import time

def safe_check(drugs, max_retries=3):
    for attempt in range(max_retries):
        resp = httpx.post(
            "https://saferx.online/api/drug_safety/check",
            headers=HEADERS,
            json={"drugs": drugs},
        )
        if resp.status_code == 200:
            return resp.json()
        if resp.status_code == 401:
            raise Exception("Invalid API key — check your X-SafeRx-API-Key header")
        if resp.status_code == 429:
            wait = int(resp.headers.get("Retry-After", 60))
            time.sleep(wait + random.uniform(0, 5))
            continue
        resp.raise_for_status()
    raise Exception("Max retries exceeded")
```

## 7. Alert Severity Reference

| Severity | Meaning | Recommended Action |
|----------|---------|-------------------|
| `CRITICAL` | Life-threatening risk (Black Box Warning, pregnancy contraindication) | Hard stop, require clinical override |
| `HIGH` | Major interaction or significant risk | Warning, require acknowledgment |
| `MODERATE` | Moderate concern, clinical attention advised | Informational display |
| `LOW` | Minor concern, generally safe | Log only, optional display |

**Alert types:** `ae_bbw` (Black Box Warning), `ddi` (Drug Interaction), `pllr_pregnancy`, `pllr_lactation`, `clinical_condition`, `clinical_population`

## 8. Parsing and Displaying Alerts

```python
result = safe_check(["Augmentin 1g", "Marivan"])

# Group by severity
from collections import defaultdict
by_severity = defaultdict(list)
for alert in result["alerts"]:
    by_severity[alert["severity"]].append(alert)

# Display
for severity in ["CRITICAL", "HIGH", "MODERATE", "LOW"]:
    alerts = by_severity.get(severity, [])
    if alerts:
        print(f"\n--- {severity} ({len(alerts)}) ---")
        for a in alerts:
            print(f"  [{a['type']}] {a['message']}")
            print(f"    Drugs: {', '.join(a['drugs_involved'])}")
```
