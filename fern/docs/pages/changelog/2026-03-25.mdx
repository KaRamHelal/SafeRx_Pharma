# March 25, 2026

## OpenAPI Spec Alignment — Field Name Corrections

**Affected:** OpenAPI spec, all SDKs (Python, TypeScript, C#), MCP Server

The OpenAPI specification has been updated to accurately reflect the field names returned by the live API after the V102 database migration. SDKs regenerated from this spec will now deserialize responses correctly.

### Breaking Changes (spec → SDK)

These fields were renamed in the V102 migration but the spec was not updated at that time:

| Field | Old (spec) | New (actual) | Notes |
|-------|-----------|--------------|-------|
| Drug ID | `SFX_ID` | `sfrx_id` | Primary identifier — used in all safety domain keys |
| Manufacturer | `manufacturer` | `manufacturer_en` | Bilingual naming convention |
| Supplier | `distributor` | `supplier_en` | Renamed + bilingual |
| DDI drug 1 | `drug_1_id` | `sfrx_id_1` | Interaction pair identifier |
| DDI drug 2 | `drug_2_id` | `sfrx_id_2` | Interaction pair identifier |

### New Fields Added to Spec

| Field | Schema | Description |
|-------|--------|-------------|
| `parent_sfrx_id` | ResolvedDrug | Parent product for strength/pack variants |
| `base_severity` | Interaction | Original severity before noise adjustments |
| `noise_type` | Interaction | Noise classification (null if clinically significant) |
| `clinical_effect` / `clinical_effect_ar` | Interaction | Expected clinical effect (EN/AR) |
| `management` / `management_ar` | Interaction | Management strategy (EN/AR) |
| `preg_t1_risk/note/ar`, `preg_t2_*`, `preg_t3_*` | ReproductiveSafetyData | Trimester-specific pregnancy risk |
| `lact_milk_level_mgl`, `lact_mp_ratio`, `lact_rid` | ReproductiveSafetyData | Lactation pharmacokinetics |

### Bug Fix

- **DDI alerts `drugs_involved`** — Fixed a bug where DDI alerts returned `["", ""]` instead of actual drug names. The alert builder was looking for `product_id_1`/`product_id_2` (pre-V102 names) instead of `sfrx_id_1`/`sfrx_id_2`.

### SDK Update Required

All SDK users should update to the latest version once regenerated:

```bash
# Python
pip install --upgrade saferx-pharma

# TypeScript
npm install saferx-pharma-sdk@latest

# C#
dotnet add package SafeRx --version latest
```

### MCP Server

The MCP server (`@saferx_pharma/mcp-server`) is a thin API wrapper and automatically reflects the corrected field names. No MCP server update is required.
