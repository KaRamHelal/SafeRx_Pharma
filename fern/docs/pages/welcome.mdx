This page describes the current SafeRx Enterprise API. Use the
[Enterprise API reference](/api-reference) and the checked-in
[OpenAPI contract](https://github.com/KaRamHelal/SafeRx_Pharma/blob/main/openapi/enterprise-v1.yaml)
for the authoritative operation and schema definitions.

Every Enterprise request is signed with `saferx-hmac-sha256-v1` — see
[Authentication](/authentication/overview) for the exact canonical-string
spec and a fully worked example.

Enterprise REST access is self-service for the existing `enterprise_free`
plan — see [Developer access](/authentication/developer-portal). Larger
plans are admin-assigned. The hosted MCP server is in preview — see
[MCP Server](/ai-integration/mcp-server).
