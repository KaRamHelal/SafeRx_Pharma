---
title: Tool use
subtitle: A safe calling pattern for agents
---

A useful tool wrapper should:

1. validate medication inputs before the request;
2. request only the domains required by the workflow;
3. preserve `check_id`, `request_id`, review state, domain status, and evidence;
4. render critical findings before explanatory prose;
5. stop and request professional review when the response requires it.

The API does not authorize autonomous dispensing or treatment changes.
