# March 17, 2026

## Conditions Enum Fix — All SDKs + MCP Server

**Affected packages:** Python v0.0.10, TypeScript v0.0.11, C# v0.0.6, MCP Server v1.0.2

The `conditions` enum was out of sync across all SDKs and the MCP server. Corrected to match the 14 conditions supported by the live API.

**Before (7 stale values):**

```
diabetes, hypertension, renal_impairment, hepatic_impairment,
cardiac_disease, peptic_ulcer, thyroid_disorder
```

**After (14 correct values):**

```
diabetes, hypertension, renal_impairment, hepatic_impairment,
cardiac_disease, peptic_ulcer, thyroid_disorder,
asthma, epilepsy, depression, anxiety, obesity, anemia, osteoporosis
```

**Upgrade:**

```bash
# Python
pip install --upgrade saferx-pharma

# TypeScript
npm install saferx-pharma-sdk@latest

# C#
dotnet add package SafeRx --version 0.0.6

# MCP Server
npx @saferx_pharma/mcp-server@latest
```
