---
title: Limits and retries
subtitle: Predictable behavior for production clients
---

Quota and entitlement decisions are server-authoritative. Clients should treat `429`, `502`, `503`, and `504` as typed outcomes and honor `Retry-After` when present.

Retry only requests marked safe to retry. Safety writes require an idempotency key; reuse the same key when retrying the same logical request. Do not retry a request with a new idempotency key unless it is a new logical operation.
