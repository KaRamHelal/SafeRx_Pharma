---
title: AI integration
subtitle: Use bounded Enterprise results in agent workflows
---

Treat the Enterprise API as a typed tool, not as an autonomous clinical decision-maker. An agent should surface `review`, `limitations`, `domain_coverage`, and `display_obligations` alongside signals and should ask for professional review when the response says so.

Use the MCP adapter or the signing-aware SDK. Do not expose credentials to model prompts, and do not infer a positive safety outcome from an unavailable domain.
