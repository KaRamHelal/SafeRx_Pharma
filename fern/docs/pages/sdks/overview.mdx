title: SDKs
subtitle: Signing-aware Enterprise client sources
---

The clients are generated from `openapi/enterprise-v1.yaml` and use the same operation IDs and HMAC request contract as the REST surface. All three are published and installable today.

| Language | Package | Install |
|---|---|---|
| Python | [`saferx-pharma`](https://pypi.org/project/saferx-pharma/) | `pip install saferx-pharma` |
| TypeScript | [`saferx-pharma-sdk`](https://www.npmjs.com/package/saferx-pharma-sdk) | `npm install saferx-pharma-sdk` |
| C# | [`SafeRx`](https://www.nuget.org/packages/SafeRx) | `dotnet add package SafeRx` |

An issued Enterprise API key is still required to make requests — see
[Developer access](/authentication/developer-portal).
