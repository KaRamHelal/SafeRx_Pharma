# March 25, 2026

## v1.2.x — SDK Publication + Bug Fixes

Publishes the spec changes from [March 24](/changelog/2026-03-24) to all SDKs and fixes additional issues found during enterprise integration testing.

### SDKs Published

| Package | Registry | Version |
|---------|----------|---------|
| `saferx-pharma` | PyPI | 1.2.0 |
| `saferx-pharma-sdk` | npm | 1.2.0 |
| `SafeRx` | NuGet | 1.2.1 |
| `@saferx_pharma/mcp-server` | npm | 1.1.1 |

### Bug Fixes

- **DDI alerts `drugs_involved`** — Fixed a bug where DDI alerts returned `["", ""]` instead of actual drug names. The alert builder was referencing pre-V102 field names.
- **C# SDK User-Agent** — Added default `User-Agent: SafeRx-CSharp-SDK/{version}` header. Without this, POST requests were rejected by the bot detector.
- **C# SDK NuGet README** — Added proper namespace (`SaferxApi`), client class (`SaferxApiClient`), and usage examples to the NuGet package page.
- **MCP server conditions enum** — Synced the 14 patient conditions with the live API. Seven stale values replaced (`liver_disease`, `kidney_disease`, `thyroid`, `blood_disorders`, `ischemic_heart`, `gout`, `osteoporosis`) with correct values (`bph`, `coronary`, `gi_bleeding`, `glaucoma`, `hyperthyroidism`, `hypothyroidism`, `parkinsons`).
