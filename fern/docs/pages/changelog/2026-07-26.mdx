## MIS public release line

SafeRx Pharma is now published from the MIS-owned public repository on version `2.0.1`. The version is coordinated across the public API contract, Python SDK, TypeScript SDK, C# SDK, MCP server, and documentation.

## What is included

- The stable five-operation Drug Safety API remains available under the documented public contract.
- Python, TypeScript, and C# clients are generated from the same OpenAPI source.
- The MCP server is released as `@saferx_pharma/mcp-server@2.0.1`.
- Documentation is published to both [docs.saferx.online](https://docs.saferx.online) and [saferx.docs.buildwithfern.com](https://saferx.docs.buildwithfern.com).

## Public-surface boundary

This release does not publish private MIS contracts, raw OCR storage fields, internal identifiers, or deployment configuration. Those remain outside the public SDK and documentation inputs.
