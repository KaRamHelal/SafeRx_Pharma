# March 24, 2026

## v1.1.0 — API Contract Audit & New Fields

### Breaking Changes

- **`SFX_ID` renamed to `sfrx_id`** — the drug identifier field in resolved drug objects now uses the actual database field name. Update any code referencing `SFX_ID`.
- **`drug_1_id` / `drug_2_id` renamed to `sfrx_id_1` / `sfrx_id_2`** — DDI interaction pair identifiers now use real field names.

### New Fields

#### Resolved Drug

- **`parent_sfrx_id`** — parent product identifier for strength/pack variants. Use this to group related products (e.g., Augmentin 625mg and 1g are variants of the same parent).

#### PLLR (Pregnancy & Lactation)

- **Trimester-specific risk** — `preg_t1_risk`, `preg_t2_risk`, `preg_t3_risk` (0-7 scale) with clinical notes `preg_t1_note`, `preg_t2_note`, `preg_t3_note`
- **Lactation pharmacokinetics** — `lact_rid` (Relative Infant Dose %), `lact_milk_level_mgl` (milk concentration mg/L), `lact_mp_ratio` (milk-to-plasma ratio)

#### DDI (Drug Interactions)

- **`clinical_effect`** / **`clinical_effect_ar`** — expected clinical effect of the interaction
- **`management`** / **`management_ar`** — clinical management recommendation
- **`base_severity`** — base severity before any adjustments
- **`noise_type`** — noise classification for low-confidence interactions

### Corrections

- **PLLR risk labels** — updated to match actual backend values:
  - `0` = No Data Available, `1` = Compatible, `2` = Probably Compatible, `3` = Use With Caution, `4` = Moderate Risk, `5` = High Risk, `6` = Contraindicated, `7` = Contraindicated — Teratogenic Risk
- **AE source field** — now always returns `"SafeRx"` (previously leaked internal data provenance names)
- **Food evidence_level** — now returns mapped values: `"primary"`, `"clinical"`, or `"reference"` (previously leaked internal enum names like `"FDA_LABEL"`)
- **Database versions** — DDI now reports V8 (was V7), PLLR now reports V3.0.4 (was V2.3)
- **DDI `source` field removed** — was documented in spec but never actually sent by the API

### SDK Updates

All SDKs updated with the new schema. See [March 25 changelog](/changelog/2026-03-25) for the latest published versions.

### Migration Guide

```python
# Before (v1.0.x)
drug_id = response["drugs"][0]["SFX_ID"]
interaction_drug_1 = interaction["drug_1_id"]

# After (v1.1.0)
drug_id = response["drugs"][0]["sfrx_id"]
parent_id = response["drugs"][0]["parent_sfrx_id"]  # new
interaction_drug_1 = interaction["sfrx_id_1"]
is_contraindicated = interaction["severity"] == 4  # V8 scale: 1-4
clinical_effect = interaction["clinical_effect"]  # new
```
